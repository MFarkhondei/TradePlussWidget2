# ویجت اندروید ترید پلاس

این پروژه یک ویجت صفحه اصلی اندروید است که اطلاعات را از Web App اسکریپت گوگل شیت پروژه «ترید پلاس» می‌خواند (اکشن `?action=widget&user=...&token=...` که در Code.gs موجود است) و مشابه طرح داشبورد نمایش می‌دهد.

## مراحل راه‌اندازی

1. **تولید توکن ویجت برای کاربر**: در ادیتور Apps Script پروژه، تابع زیر را برای هر کاربر یک‌بار اجرا کنید و توکن خروجی را در Logger.log ببینید:
   ```js
   generateWidgetToken('نام_کاربری');
   ```
2. این ریپو را در گیت‌هاب push کنید (یا مستقیم زیپ را در یک ریپوی جدید آپلود کنید).
3. به تب **Actions** بروید و ورک‌فلو «Build TradePlus Widget APK» را به‌صورت دستی اجرا کنید (workflow_dispatch) یا با هر push روی main خودکار اجرا می‌شود.
4. بعد از اتمام بیلد، از بخش Artifacts فایل `tradeplus-widget-apk` را دانلود کنید (یک zip حاوی APK دیباگ).
5. APK را روی گوشی نصب کنید (نیاز به فعال‌سازی نصب از منابع ناشناس).
6. ویجت «ترید پلاس» را به صفحه اصلی اضافه کنید؛ در صفحه تنظیماتی که باز می‌شود:
   - آدرس Web App (لینک exec دیپلوی‌شده)
   - نام کاربری
   - توکن تولیدشده در مرحله ۱
   را وارد و ذخیره کنید.

ویجت هر ۳۰ دقیقه به‌صورت خودکار بروزرسانی می‌شود و با ضربه روی آیکن رفرش هم می‌توان آن را دستی بروزرسانی کرد.
